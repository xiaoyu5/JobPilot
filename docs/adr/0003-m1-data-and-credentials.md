# ADR-0003 · M1 本地数据、简历解析与凭据

状态：已实施；浏览器运行方式由 [ADR-0004](0004-boss-native-chrome.md) 更新。日期：2026-10-22。

## 数据与事实审核

唯一 Node Worker 持有本地 SQLite 数据库。采用捆绑 Node 22.23.2 的 `node:sqlite`，避免需要为不同机器另编译原生扩展。该版本 API 仍带实验性提示，因此固定运行时，并通过发行包集成测试验证真实读取、写入、重启与资源路径。

数据库在私有应用目录内，文件权限 0600；启用 WAL、FULL 同步、外键、busy timeout 和事务迁移，`user_version=1`。配置、事实来源与审核版本、冻结快照、单个搜索方案、岗位、任务和事件持久化。预留评估、草稿和 outbox 表，不开放发送。备份恢复、导出和彻底清除将在后续数据管理工作中提供，M1 不宣称已支持这些入口。

每条简历事实保留来源文件名、页码（PDF）、段落与脱敏原文，不将原文件复制到数据库。导入一律待审核，修改撤销确认；更新使用条目版本检测冲突。冻结仅包含明确确认的事实，任何后续修改使当前冻结版本失效，并使未来草稿失效。相同文件按内容哈希防止重复导入。

DOCX 使用 Mammoth 1.13.0，PDF 使用 unpdf 1.9.1 / PDF.js 6.4.299 的纯 JavaScript 解析；不执行 OCR，不调用 LLM。限制文件 8 MiB、PDF 30 页、DOCX 声明展开大小 24 MiB、文本 100k 字符、每次 300 条、事实库 500 条。发行资源中的独立 Node worker thread 有 20 秒时限和 256 MiB V8 堆限制，支持退出时取消。PDF 字体、CMap 与 WASM 资源随 App 打包，资产读取仅允许指定目录和文件名。

## 模型凭据

非敏感模型配置存 SQLite；API Key 由 Rust 通过 security-framework 3.7.0 写入 macOS Keychain。账号按应用数据目录区分，凭据绑定 Base URL，避免修改端点后复用旧 Key。WebView 仅可查询“已保存”状态，测试保存的配置时由 Rust 从 Keychain 取出并直接交给 Worker，不回传 Key。

本机 `.env.local` 继续仅用于开发验证，权限 0600 且忽略 Git。它不是产品凭据存储，不进入 App / DMG。原生测试使用匿名假 Key 完成真实 Keychain 存、读、删；浏览器 UI 测试仅模拟原生桥中的 Keychain 和文件选择器，数据操作连接真实 Worker。

## 浏览器与只读任务

会话仅保留在应用专用 Chrome Profile，真实会话采用普通可见 Chrome 与原生 Apple Events；标准 Playwright 保留用于匿名测试，不导出 Cookie。手动登录后以可靠的页面身份标识判定状态；头像占位不视为登录。验证或未知页面停止采集。上游参考与实测区别记录在 [get_jobs 登录态研究](../research/get-jobs-session.md)。

搜索方案只接受 BOSS 官方搜索链接及允许的筛选参数，关键词和最多 50 条的上限单独保存。M1 有上限地滚动搜索页并读取相应 JD；跨页分页未提供。按平台岗位 ID 去重，匿名演示与真实 BOSS 数据分开标记。撤销授权、人工暂停或 Worker 中断均不自动续跑。

桌面与 MCP 复用同一个 Worker 和权限检查。MCP 暴露状态、只读搜索、岗位列表、任务读取和暂停，共六个工具。Auto / 发送均未开放；AI 匹配、草稿审核属于 M2，真实发送属于 M3。
