# ADR-0007：GUI 授权、持久化发送意图和不确定结果核验

日期：2026-10-22。状态：M3 实施；真实 BOSS 发送仍须单独授权并验证。沿用 [ADR-0004](0004-boss-native-chrome.md) 的普通专用 Chrome + Apple Events 和 [ADR-0006](0006-env-credentials.md) 的 `.env` 凭据方案。

## 授权与门禁

首次启动仍为 Preview，真实发送和 Auto 均关闭。界面先确认分数阈值、单轮/每日条数、最小间隔、每日轮次、时区和允许时段，才能启用真实发送。默认建议 80 分、5 条/轮、15 条/日、15 秒间隔、2 轮/日；这些是应用自设限制，不代表平台允许额度。

Review 先检查并展示具体岗位、公司和最终文本，再勾选确认，生成 5 分钟内有效的一次性计划。草稿版本、事实版本、JD、目标身份、模型配置、规则或本地审核状态变化后失效。Auto 另有会话级明确确认；重启、配置变化、急停或撤销时关闭。MCP 可以在有效 Auto 授权内启动一轮，但不能授予或扩展权限。

Rust 每次启动生成独立 GUI capability，只经受保护的原生 command 注入需要授权的 Worker 请求，Worker 用常量时间比较校验。普通 socket token 不能作为 GUI 授权。手动保存/重载模型环境时递增非秘密配置修订号，即使只更换 API Key 也使旧确认失效；普通启动自动加载不递增，避免误伤持久化检查点。capability 不落盘，不返回前端或 MCP，在 Node 启动后立即移除环境变量，避免继承到 Chrome。该边界用于区分受信任原生界面和外部 MCP 调用，不声称能抵御同一用户权限下的恶意进程。

每次发送重新检查当前冻结的已确认事实、报告、无硬缺口、分数阈值、文案审计和长度、真实来源、未沟通标记、目标岗位和招聘人、正常登录状态、页面结构、时段、额度和模型服务。发送并发为 1，收集/匹配任务与发送互斥。发前模型服务健康检查失败时保留队列并停止写入。

## Outbox 和恢复

SQLite v3 为发送增加 execution_mode、检查点、规则版本、事实/草稿版本、内容快照与哈希、操作阶段及授权记录。保留旧 runs.mode 的 preview CHECK，通过新的 execution_mode 表达模式，避免重建被外键引用的 runs 表。v2 升级前创建 0600 的 `jobpilot.pre-m3.sqlite` 备份。

在任何编辑或点击前，以 FULL 同步事务写入 `SEND_INTENT` 和 `SENDING`，同时推进检查点。岗位 ID 和招聘人 ID 各有唯一索引；已发、处理中、不确定以及人工跳过都保留永久去重锁，不自动补发。所有意图均占用当日额度。等待最小间隔时可取消。间隔取发送意图与最近提交完成时间的较晚值；慢编辑页面不会缩短相邻实际提交的间隔，重启后仍保留该限制。

点击派发前持久化 `CLICK_DISPATCHED`。仅当目标会话出现内容精确一致、具有可靠消息标识且不在发送中/失败状态的可见发出消息时，标记 `SENT_CONFIRMED`。无确定证据、点击后异常或中断都进入 `NEEDS_VERIFY`，锁定后续发送并急停。重启将遗留 `SENDING` 转为 `NEEDS_VERIFY`，撤销授权，不自动恢复。

核验只能读取可见会话，不重新提交。用户也可在真实页面人工确认已发，或确认未发并跳过；两种结果明确区别于页面自动确认。更新核验状态和计数使用同一事务。继续任务必须再次确认剩余文案；只处理尚无意图的条目。急停快捷键为 ⌘.。休眠/时钟明显跳变、Chrome 关闭、登录失效、验证码或未知 DOM 均停止；不做绕过。

## 浏览器边界

Swift 原生接口仅执行随应用发布的固定动作脚本，参数通过 stdin JSON 传递；不接受外部任意 JS、选择器或 URL。每次动作重新核对正常登录、可见岗位和招聘人标识、精确文案、短时授权与意图标记。输入框已有其它内容时停止，避免覆盖用户草稿。

只允许唯一可见编辑框及明确发送按钮，或明确的编辑预览入口。**不能把“立即沟通”视为安全打开编辑器的动作**：它可能直接发出平台默认招呼语。未确认其行为之前不点击，不以默认文案替代用户确认文本。页面没有可靠身份或编辑入口时返回 NEEDS_HUMAN / ADAPTER_CHANGED。

不使用 BOSS 私有接口、前端内部状态、Cookie 提取、反检测或验证码绕过。聊天记录不发送至 LLM，核验脚本只返回对应消息的确认状态与标识，不返回聊天全文。匿名夹具验证与真实账号验证分别记录；夹具通过不等于真实首次沟通流程已验证。
