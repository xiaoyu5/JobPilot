# ADR-0010：复盘、诊断与本机数据恢复

日期：2026-10-22。状态：M4 实施。SQLite v5 新增 `job_outcomes` 和无外键的 `contact_locks`，v4 升级前保存 0600 一致快照 `jobpilot.pre-m4.sqlite`。延续 [最终真实验收安排](0009-final-live-acceptance.md)。

## 复盘口径

以已确认至少一条首联消息的唯一岗位为联系分母；两步首联仍是一个岗位。按首联意图日期筛选批次，回复、拒绝、邀面由用户标记；拒绝和邀面均蕴含回复。未确认的点击不算已发送，已确认默认招呼的部分完成单独展示。其它历史沟通的手动标记单列，不能使 JobPilot 回复率超过 100%。这不是已读检测或自动邀面识别。

结果标记有乐观版本检查，备注仅存本机。标记已回复会保留已沟通状态；标记拒绝立即保存联系锁。后续编辑统计不撤销拒绝锁，已有会话在读取后按原规则持续停止联系。

## 诊断与文件

诊断采用字段白名单：运行时版本、状态、数量、任务 UUID、已知事件类型、时间和 traceId。不序列化任意对象，不导出自由事件文字、原始履历、JD、招聘人标识、聊天、文案、备注、路径、URL 或配置值。输出 JSON 为 0600，本机目录为 0700；目录符号链接拒绝写入。

备份用 SQLite `VACUUM INTO` 获取一致快照，包含业务数据库，故按私密文件处理；不打包 `.env`、Chrome Profile 或原件。原生“另存到…”只接受应用导出目录内的文件，新建到用户明确选择的外部位置，拒绝覆盖已有文件及写入活动数据目录。Finder 显示也限定应用的备份/导出目录。

## 恢复和重置

恢复限当前 v5 结构、128 MiB；只读检查结构指纹、完整性及外键，拒绝其它结构、附加触发器、符号链接和变化的文件。复制到私有暂存目录后显示范围，确认计划五分钟过期。GUI 确认提交后冻结后续修改，重启时在唯一 Worker 锁内、创建 Application 之前执行。

当前数据先留备份。恢复旧库时，将当前永久首联锁、按入站消息的回复锁和拒绝标记展开至已明确关联的业务标识，合并入无外键的 `contact_locks`；旧快照缺少对应岗位或草稿时，仍能阻止再次联系。统计恢复至快照时点，后续联系锁独立保留。当前未核验的发送必须先处理；恢复目标中的中断发送继续按原规则锁定。

恢复关闭发送、两种 Auto、BOSS 授权，丢弃旧确认计划；`.env` 和浏览器登录不由备份恢复。应用正常重读自己的现有 `.env`。替换前写入完成标识，采用同目录原子替换；重启遇到已完成标识时只清理暂存。校验失败且当前库健康时，取消操作、保留可打开的数据并显示错误。

全量重置需要 GUI 输入精确确认文字，先关闭经过归属校验的专用 Chrome，再在重启时清除应用拥有的数据库、Profile、应用内配置、备份和导出。原始简历、外部保存的备份及外部配置文件不删除。重置会清除联系锁，因此界面明确要求提前外存备份；新库恢复为无事实、无浏览器授权、无发送授权的状态。

## 清理与权限

默认保留周期为 90 天，可保存为 7–3650 天。用户按来源和截止日期预览并确认清理；只有未沟通、未排队、无发送和无结果标记的岗位可清理，相关匹配与草稿一并删除。事实、会话拒绝及联系锁保留。计划绑定确切范围，数据变化或过期后重新预览。

数据操作、导出和结果标记需要原生 GUI capability；普通 IPC/MCP 不授予这些权限。数据维护与模型/浏览器任务互斥，待重启操作阻断后续修改。MCP 继续维持原有十个工具，不增加发送授权或数据清除工具。
