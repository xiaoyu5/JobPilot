# ADR-0011：GitHub DMG 分发，正式签名与公证可选

日期：2026-10-22。状态：已接受。用户明确只需将 release DMG 放在 GitHub，不上架 App Store；在说明临时签名的安装差异后，用户回复“可以，继续未完成的”，并提供仓库 `https://github.com/xiaoyu5/JobPilot.git`。

## 决策

目标为 GitHub 源码及 DMG 分发。当前使用完整 ad-hoc 签名，不将 Developer ID 会员、正式签名或 Apple 公证作为 GitHub 预发行的前置条件。它们保留为可选的安装体验改进，未执行的项目不标为通过，也不暗示临时签名可通过默认 Gatekeeper 检查。

随发行提供安装说明、真实验证范围、独立可加载的只读扩展及 SHA-256。最终真实发送仍按 ADR-0009 验收；真实发送尚未通过时，仅准备预发行版，不宣称全面可用。独立干净 macOS 环境和实际下载后的首次安装继续单列待验收。

原始需求含真实简历背景，保留本机冻结副本，排除在公开源码与发行附件之外。公开产品范围使用 `docs/product-scope.md`。本机 `.env`、数据库、Chrome Profile、私密备份、诊断记录和构建目录同样不提交。此决策更新 ADR-0002 和 ADR-0009 中正式发行签名的口径，不修改原始需求。
