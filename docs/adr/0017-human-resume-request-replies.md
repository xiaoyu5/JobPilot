# ADR-0017：附件请求的人工文字回复

日期：2026-10-23。真实回复验收遇到招聘人索取附件简历的请求。该请求依既定规则进入 REVIEW，0.5.0 缺少从 REVIEW 准备人工文字确认的入口。此次仅补齐此入口，不开放自动附件操作或模型代替用户同意。

用户在 GUI 选择“同意”或“暂不提供”，再核对固定文字并独立确认发送。未选择时不能准备；普通 IPC/MCP 不能创建这类计划。文字分别为“您好，可以的。”与“您好，暂时先不提供附件简历，谢谢理解。”，不声称附件已经发送。处理请求及决定不交给模型；原有发送健康检查仍有效。

计划绑定唯一会话、最新请求 ID、完整历史、当前事实/规则指纹与五分钟时效。只有未拒绝且无回复意图的最新附件简历请求可用；验证码、银行卡、转账、链接等请求不提供此快捷处理。发送仍使用原有 chat_outbox、额度、串行任务和页面核验；新消息、拒绝、过期或上下文变化会阻断。Auto 不会选择或提交人工计划。

此操作只向聊天编辑框提交一条明确文本，不点击 BOSS 的“同意”卡片按钮、不选择文件、不上传或交换附件；需要附件时由用户在 BOSS 自行处理。数据库保持 v5，事实、旧草稿和历史发送不自动修改。
