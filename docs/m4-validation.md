# M4 功能与发行候选验证记录

日期：2026-10-22。版本：0.4.0，ARM64。真实发送按 [ADR-0009](adr/0009-final-live-acceptance.md) 统一留到全部功能完成后的最终验收。

## 已实现功能

- 求职复盘：手动标记回复、拒绝、邀面和备注；按已确认首联岗位统计分母，区分首联消息数量、部分完成、人工确认和其它历史沟通。统计更改不撤销拒绝锁。
- 脱敏诊断：字段白名单导出状态、计数、事件类型与 traceId，省略自由文字、履历、JD、聊天、文案、备注、身份、路径、URL 和凭据。
- 私密备份及原生另存：0600 SQLite 一致快照，原件、`.env` 和 Chrome 登录不打包。
- 恢复：当前 v5 结构与完整性检查、哈希和过期确认、范围预览、重启前冻结操作、唯一 Worker 锁内替换、当前库备份、保留较新联系锁和拒绝记录、撤销发送及访问授权。
- 故障恢复：变化的恢复文件使该操作停止，健康的当前库继续可用并显示处理提示。
- 岗位保留与清理：默认 90 天的可配置周期，按来源/日期预览确切范围，保护已沟通、已排队、有发送和结果记录的岗位；简历、拒绝及联系锁保留。
- 全量重置：精确输入确认文字后重启，清除应用内数据库、专用登录、配置、备份和导出，保留外部文件。
- MCP：维持十个工具，版本同步 0.4.0；权限仍由原生 GUI 控制。
