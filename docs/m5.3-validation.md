# 0.5.3：首次安装与收尾验收

2026-10-23，用户选择在当前 Mac 卸载、清空数据并重装，配置仅在本机保留；空数据验收后恢复原业务数据。原 App、应用数据、专用 Chrome Profile、WebKit、缓存及偏好均先备份到本机忽略目录。该范围不等同于独立 macOS 用户或另一台 Mac：系统自动化权限与 Gatekeeper 历史未重置。

从 GitHub 已核验的 0.5.2 DMG 重装后，首次启动失败且没有 Worker。原因是桌面进程先设置 `Command::current_dir(data_dir)`，但数据目录尚不存在，Node 来不及执行创建目录逻辑。之前的安装测试使用 `mkdtemp` 预建了数据目录，未覆盖这个条件。0.5.3 改为桌面进程先创建目录并设为 0700，再启动 Worker；安装回归改为临时根目录下尚不存在的子目录，检查真实首次创建。

类型检查、113/113 匿名测试及 Worker/UI 构建通过。首次受限运行因本机监听和隔离 Chrome 的沙盒限制失败，允许测试所需权限后完整重跑通过；不将该次环境失败记为产品通过。
