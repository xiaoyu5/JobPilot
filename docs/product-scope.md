# JobPilot 产品范围

JobPilot 是在个人 Mac 本地运行的 AI 求职工作台。当前目标为 macOS 13+ Apple Silicon，V1 仅适配 BOSS 直聘。用户自行配置 OpenAI 兼容服务，使用自己的可见 Chrome 登录会话；不需要部署云端服务。

原始开发需求含用户简历背景，作为本机冻结资料保留，不随公开源码提供。本页概述公开产品范围，实现变更由 `docs/adr/` 记录。

## 工作流程

1. 从 DOCX 或文字型 PDF 导入简历，用户逐条核对事实、修正并明确确认，再冻结事实版本。
2. 人工登录专用 Chrome，按已保存的关键词和搜索页条件只读采集岗位及 JD。
3. 对本机岗位执行规则筛选、模型结构化匹配、事实引用与话术审计，将草稿加入审核队列。
4. 默认只预览。真实操作需在 GUI 启用发送规则、核对目标与最终文案，Auto 独立授权；MCP 不提供授权工具。
5. 首次联系区分平台默认招呼与 AI 文案；已有会话区分拒绝、等待、新问题和需人工处理，结果不明时停止且不自动重发。
6. 按已确认首联记录复盘回复与邀面，通过脱敏诊断、私密备份恢复和清理管理本机数据。

## 实现边界

事实需用户确认，模型不能自行添加工作或项目经历。必要 JD 和已确认事实会发送至用户配置的模型服务；原始简历、浏览器 Cookie 和聊天全文不发送给模型。验证码与平台验证由用户处理。未知页面、身份不明、拒绝或发送结果不确定时停止。

配置、数据库和专用 Chrome Profile 均保存在本机。参考 `loks666/get_jobs` 的会话保存思路，未直接复制其受限许可源码。不会自动修改在线简历、交换联系方式、发送附件或绕过平台校验。
