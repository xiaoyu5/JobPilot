# JobPilot 0.4.0 · 预发行版

本地 AI 求职工作台，支持 macOS 13+ / Apple Silicon。此版本采用临时（ad-hoc）签名，未做 Apple 公证；首次安装可能需要在“系统设置 → 隐私与安全性”手动允许打开。

## 功能

- 专用 Chrome 人工登录，保存独立 Profile，只读搜索和采集 BOSS 岗位/JD。
- DOCX / 文字型 PDF 简历事实审核与冻结，连接自己的 OpenAI 兼容服务匹配岗位、生成有事实来源的中文草稿。
- 审核队列、受控首联和已有会话助手；区分默认招呼、等待、拒绝和新问题，保留联系及拒绝锁。
- 求职复盘、脱敏诊断、私密备份与恢复、过期岗位清理及本机数据重置。
- 自带 Node 运行时，十个 MCP stdio 工具共用桌面 Worker。

## 验证与限制

75 项自动测试、UI 集成、本机安装、升级、重启和 MCP 验证通过。真实 BOSS 登录与只读岗位采集已验证。

**真实首联、真实会话回复和 Auto 尚未完成最终验收。** 默认 Preview，所有真实发送及 Auto 关闭。首次点击“立即沟通”会立即发出平台默认招呼，AI 文案是第二条消息，需在界面单独核对并确认。

独立干净 Mac / 新用户环境和从 GitHub 下载后的首次安装尚待验证。当前仅提供 ARM64 包，不能用于 Intel Mac；BOSS 功能依赖自行安装的 Google Chrome 及用户手动授予的自动化权限。页面结构变化或身份不明时停止处理。

## 下载文件

- `JobPilot_0.4.0_aarch64.dmg`：桌面应用。
- `JobPilot_BOSS_Reader_0.1.2.zip`：可选只读扩展，解压后手动加载。
- `INSTALL-macOS.md`：安装、配置和权限操作说明。
- `SHA256SUMS.txt`：文件校验值。
- `release-manifest.json`：版本、架构、签名状态和打包检查结果。

API Key、简历、数据库和 Chrome 登录数据不随发行包提供。模型服务地址、模型及凭据由使用者自行配置。
