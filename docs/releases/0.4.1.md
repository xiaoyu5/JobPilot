# JobPilot 0.4.1 · 预发行修复版

修复同一岗位重复读取后草稿被误判为失效的问题，并简化审核队列的恢复操作。

## 修复内容

- JD 使用页面实际渲染的正文，排除混入 `textContent` 的隐藏文字。隐藏标签变化不再触发岗位版本变化；真实可见要求发生变化时，原匹配与审核仍会失效。
- 失效记录可直接点击“重新匹配并生成草稿”，无需离开审核队列。新草稿回到“待你审核”，不自动沿用旧审核。
- “检查发送条件”改名为“发送前检查”，页面说明此按钮只打开确认窗口；最终点击“确认发送”才提交消息。

## 安装与验证范围

支持 macOS 13+ / Apple Silicon，自带 Node，BOSS 功能需要自行安装 Google Chrome。当前使用临时（ad-hoc）签名，未做 Apple 公证；安装方式见附件 `INSTALL-macOS.md`。

76 项自动测试、生产构建和匿名审核队列集成验证通过。真实发送、真实新提问回复和 Auto 仍待最终验收，默认 Preview。首次“立即沟通”会先发平台默认招呼，再发已确认 AI 文案，共两条，需在应用中核对。

提供 DMG、可选只读扩展 ZIP、安装说明、发布说明、manifest 和 SHA-256 清单。不包含 API Key、简历、数据库或 Chrome 登录数据。独立干净 Mac / 新用户环境首次安装仍待验证。
