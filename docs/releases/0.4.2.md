# JobPilot 0.4.2 · 应用层匹配修复预发行版

改善普通 App 研发岗位被过严证据规则挡住的问题，并支持直接补充真实事实。

- 匹配按实际应用层能力评估，不要求简历逐字复述 JD。已确认的独立 App 开发与上线经历可支持普通需求、文档和自测流程；常规细节作为面试核对项。
- 专项技术、底层、后端、商业年限和资质继续核对，不把通用 App 能力扩写为全部框架或内核专长。校准不自动抬高分数。
- 简历事实库新增“补充一条真实事实”，保留用户来源，默认待审核。原工作和项目记录不变，修改仍撤销确认。
- 草稿优先展示岗位相关技术、项目或独立交付价值，仍保留完整已确认事实及限定语。

80 项自动测试、生产构建及匿名界面流程通过。真实发送、真实回复及 Auto 仍待最终验收，默认 Preview；事实确认不等于发送授权。

支持 macOS 13+ / Apple Silicon，自带 Node；BOSS 需要自行安装 Chrome。采用临时（ad-hoc）签名，未做 Apple 公证，安装方式见附件 `INSTALL-macOS.md`。提供 DMG、只读扩展、说明及 SHA-256 清单，不包含个人配置或登录数据。
