# JobPilot 0.4.3 预发行版

新增企业微信群机器人通知：真实岗位草稿待审核、已读取会话需人工处理、发送结果待核验或任务异常时，向手机企业微信发送数量汇总。设置中可填写和修改 Webhook、测试连接及查看最近推送状态。

这是单向提醒。用户在手机 BOSS 查看消息，或回 Mac 的 JobPilot 审核；企业微信群内回复不能批准发送。通知不额外扫描整个 BOSS 收件箱，App 退出或 Mac 休眠时不检查。

默认关闭；地址保存在本机 `.env`，支持 `WECOM_WEBHOOK_URL` 和 `HOOK_URL`。相同事项去重、合并并限制频率；失败重试有上限，通知异常不影响岗位或审核数据。通知不包含简历、草稿、聊天正文或凭据。

87 项匿名测试、通知 UI、App/DMG 构建及安装验证结果见 [0.4.3 记录](https://github.com/xiaoyu5/JobPilot/blob/main/docs/m4.3-validation.md)。真实企业微信收件待填写机器人后实测；BOSS 真实发送仍按独立最终验收执行。

仅 Apple Silicon、macOS 13+。App 捆绑 Node。DMG 使用完整 ad-hoc 签名，未公证，不宣称通过默认 Gatekeeper；安装步骤见附件。附件不包含用户配置、账号数据或原始简历。
