# JobPilot 0.4.4 预发行版

修复岗位池的 BOSS 自定义数字字体乱码，分离职位名和薪资；同时修复旧缓存，详情刷新会更新实际标题和薪资。未知字体不会被猜成数字。

改进 DOCX 事实提取：保留项目归属和来源，识别个人优势、开源项目及学历/年限信息，排除联系方式和空标题。导入界面支持合并去重，或明确选择以新版替换旧简历事实，保留手动补充和历史快照；新版事实仍待人工确认。

修复 JD 只写专业要求时漏传教育事实的问题；问候语优先呈现相关项目经验，简洁模式为事实正文保留更多字数，仍完整保留事实与限定语。手动编辑可换用其他完整已确认事实，同步保存引用并撤销旧审核。

适配真实岗位的沟通弹窗和独立“已发送”回执。默认招呼后中断且 AI 从未提交时，提供单条 AI 的独立 GUI 确认，保留原意图、额度和去重锁；提交结果未知的 AI 不能重发。

98 项匿名测试、导入/岗位及续发确认 UI 和 App/DMG 安装验证通过。真实简历和可见 BOSS 岗位字段已在本机核对；详情见 [0.4.4 验证记录](https://github.com/xiaoyu5/JobPilot/blob/main/docs/m4.4-validation.md)。真实发送结果按独立最终验收记录，不以模型评分或匿名测试代替。

仅 Apple Silicon、macOS 13+，捆绑 Node，使用完整 ad-hoc 签名，未公证。附件不包含用户简历、事实库、账号数据或本机配置。
