# JobPilot 0.5.0 预发行

- 会话助手新增有上限的联系人扫描、历史向上加载和只读消息监测；新发现会话不会自动加入发送范围，拒绝后持续停止联系。
- 岗位池已沟通岗位可通过“继续沟通（不发送）”进入消息页。
- 新增自然精炼文案及原事实对照；生成后必须逐条人工审核。
- 执行记录新增连续任务：搜索、读取 JD、匹配、生成草稿、入队；支持从持久化检查点恢复。
- 新增应用运行期间的每日排程。默认预览，Auto 仍需独立授权；重启、休眠和急停后关闭。
- 支持多个搜索方案、有限分页及每页滚动次数设置，最多采集 50 条并跨页去重。
- BOSS 只读扩展更新为 0.2.0，权限仍仅 activeTab 和 scripting。已加载旧版时，重载扩展后在 BOSS 消息页重新连接。

本版采用临时签名，支持 macOS 13+ Apple Silicon。真实聊天回复、Auto、手机通知及独立干净环境仍需验收，不以匿名测试代替实际结果。既有首次沟通验收范围见文档。
