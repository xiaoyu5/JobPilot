# JobPilot 0.5.1 预发行

修复会话助手遇到附件简历请求时只能转人工、无法准备文字回复的问题。

- “需人工判断”的明确附件请求可点击“人工处理附件请求”。
- 用户先选择同意或暂不提供，再预览并最终确认固定文字。
- 仅发送这条文字，不点击平台同意按钮、不选择或上传文件。
- Auto 不代替用户作决定；身份、完整历史、最新消息、拒绝、额度及去重检查保持。

106 项匿名测试、聊天界面回归及最终 DMG 安装验证通过。所选会话由用户人工处理，JobPilot 未提交聊天回复；已有会话真实发送仍待验收。应用继续使用临时签名，支持 macOS 13+ Apple Silicon。
