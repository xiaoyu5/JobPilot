# JobPilot 使用指南

安装、Chrome 权限、模型配置、可选只读扩展及企业微信设置见 [macOS 安装说明](install-macos.md)。

## 准备简历事实与模型

导入 DOCX 或文字型 PDF，逐条核对提取事实，必要时修正、移除或补充，再冻结已确认版本。原件不复制入库，提取文本和来源保存在本机。更新简历可合并去重，也可明确替换旧简历事实，保留手动补充与历史快照；新条目仍待确认。

“设置”支持填写模型地址、模型名和 API Key，也可加载 `.env` / `.env.local` 的完整路径。保存后写入当前配置文件，下次启动自动读取，不使用钥匙串。Key 留空保留现值，勾选可清除，已保存值不回显。文件使用 0600 权限并原子替换，数据库只记录路径和非敏感参数。格式见 [.env.example](../.env.example)。

目前默认只允许本机模型端点；局域网 IP 需要明确授权。必要 JD、已确认事实和回复所需的最新脱敏问题会交给这个服务，其后端可能转发至远程模型。

## 采集与匹配

在专用 Chrome 手动登录 BOSS，保存关键词及手动选好条件的搜索页链接，再开始只读采集。浏览器将登录会话保存在独立 Profile，不另行导出 Cookie。可保存、切换多个方案，并配置最多结果页数和每页滚动次数。每次最多 50 条，仅使用正常页面的唯一下一页入口，跨页按岗位 ID 去重。采集有数量及滚动上限；登录失效、验证码或未知结构会停止。

可在岗位详情逐条匹配、生成草稿和加入审核队列，也可从总览对本机岗位池执行 Dry Run。Dry Run 不操作浏览器或发送消息。城市和薪资条件默认不限，匹配阈值和话术长度可在设置调整。

“生成自然文案（需审核）”可精炼已确认事实，展示每句原文对照；模型证据核对仅为辅助，仍需逐句人工审核，这类草稿未经审核不会进入 Auto。传统草稿引用已确认完整事实并保留限定语。你可换用冻结版本中的其他完整事实；新增或精炼经历需先在事实库确认。修改事实、JD、模型或规则会使旧匹配及审核失效；修改草稿会撤销旧审核。失效队列可点击“重新匹配并生成草稿”恢复。

## 连续任务和每日排程

“执行记录”可按当前保存方案依次采集、读取 JD、匹配并生成草稿，默认预览不发送，界面默认自然精炼并等待审核。选择 Auto 时使用完整原文事实，仍需先独立授权首联 Auto；只发送本次任务产生的合格队列项。

暂停或异常后，可在该连续任务行点击“从检查点继续”。已经完成的 JD 和匹配不从头重做；事实、模型、规则或搜索方案改变后必须新建任务。发送子任务有独立意图和核验记录，不能通过重开连续任务重发。

每日排程保存时间、时区、方案和模式，仅当前进程存活时启用；重启、休眠/时钟跳变、急停后关闭，不唤醒或补跑。排程不能开启 Auto，每个本地日期只触发一次。

## 首次沟通：职位详情的“立即沟通”

1. 在“设置 → 受控发送”核对并保存真实发送开关、阈值、限额、间隔和时段。
2. 在审核队列核对最终文案，标记已审核，再点击“发送前检查”。括号中的数量表示岗位数，确认窗口展示实际消息数。
3. 首次点击 BOSS“立即沟通”就会发送平台默认招呼，并弹出沟通窗口；不是只打开预览。
4. 按确认的两条计划，核验默认招呼后再发送已批准的 AI 文案，两条分别占用消息额度。

结果不明会保留原发送意图和去重锁，不自动重发。若停在默认招呼之后，且持久记录证明 AI 从未提交，可在底部“发送与核验记录”点击“检查仅续发 AI 文案”；只读核验目标和默认回执通过后，需重新确认仅发送这一条 AI。原意图、额度和轮次不重复，默认招呼不重发。已经进入 AI 提交阶段但结果未知的记录不允许此操作。

## 已有会话：点击“继续沟通”进入聊天消息页

“继续沟通”跳转 BOSS 聊天消息页面。岗位池中已沟通岗位可点“继续沟通（不发送）”进入消息页，再使用“会话助手”读取当前选中的已有联系人，不重复执行首次招呼。

- **已拒绝**：停止联系，保留拒绝记录。
- **等待对方回复**：不重复追问；平台默认招呼和 PK 卡不算对方回复。
- **有新问题**：基于已冻结事实准备回复，核对后确认发送。
- **需人工处理**：薪资、面试、联系方式、附件、不完整历史或不明确内容交给用户处理。

只读扩展 0.3.0 可识别可见联系人。页面刷新或重启后，单次连接会失效；可在扩展中自愿开启“记住只读连接”，另行允许 BOSS 网站访问后自动恢复，断开时同时撤销。应用将连接失效与真正找不到联系人分别提示，并核对当前组件明确提供的招聘人别名。点击“扫描联系人与新消息（只读）”可有限滚动并逐批读取，或独立开启每 30 秒的只读监测；最多 100 个联系人、每批轮换 10 个。扫描会切换会话，不读取隐藏列表对象或发送消息。历史最多向上加载 8 次，超过 100 条或仍不完整时交给人工。监测异常、重启或急停后关闭，新联系人不会自动加入 Auto。

附件简历请求仍需人工决定。若出现“人工处理附件请求”，选择同意后，预览并确认发送 BOSS 中已上传的附件简历，不另发文字招呼；若需选择版本，仅使用唯一附件或界面明确选中的默认版本，无法确认时停止。暂不提供时仍可发送固定拒绝文字。已在 BOSS 人工处理的请求不再补发。若处于急停，先在“设置 → 受控发送”解除急停，再重新准备。

自动回复需另外勾选具体会话并确认启用，按对方消息 ID 去重。首联 Auto 与聊天 Auto 独立，重启后关闭；MCP 不能代为授权。模型只接收最新脱敏问题和必要事实，不接收联系人列表或聊天全文。部分页面需手动连接[只读扩展](../extensions/boss-reader/README.md)以提供可靠身份，连接本身不授权发送。

顶部急停按钮或 ⌘. 可停止后续操作，已提交的消息不可撤回。身份不明、历史不完整、页面变化或结果未知时停止。核验后可明确标记已发、仅默认已发并跳过 AI，或未发并跳过；这些人工结果与页面自动确认分别记录。

## 企业微信提醒与求职复盘

可配置企业微信群机器人，接收待审核、需人工处理、待核验和异常的数量摘要。通知为单向提醒，群内回复不能批准发送；回 Mac 审核，或在手机 BOSS 查看消息。App 退出或 Mac 休眠时不检查；消息提醒依赖已读入的会话或已启用的只读监测，不接收平台后台推送。

“求职复盘”可标记真实回复、拒绝、邀面和备注。回复率、邀面率以 JobPilot 已确认首联的岗位数为分母，两条首联只算一个岗位。平台 PK 卡、未确认发送和其它历史沟通不进入分母。拒绝标记会保留停止联系锁，修改统计标记不会解除它。

## 数据与诊断

“数据与诊断”可导出脱敏 JSON、创建私密 SQLite 备份、恢复和清理岗位。诊断省略简历/JD、聊天、备注、路径、URL、凭据和原始事件文字。私密备份含个人数据，保存为 0600，不包含 API Key 文件、原始附件或 Chrome 登录目录。

恢复接受当前 SQLite v5 的 JobPilot 备份，检查结构、完整性、哈希和时效，展示范围并在确认后重启。恢复前保留当前私密备份；备份之后产生的联系锁和拒绝记录继续保留。发送、Auto 和 BOSS 访问授权关闭，模型凭据不从备份恢复。

过期岗位默认按 90 天预览，清理前显示数量；已沟通、已排队、有发送或结果记录的岗位保留。清除全部本机数据需输入确认文字并重启，范围包含应用内备份和专用 Profile；外部另存备份、原始简历及外部 `.env` 不删除。

实际验证范围见[文档索引](README.md)和[发行验收清单](release-readiness.md)。
