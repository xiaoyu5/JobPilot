# 可选 BOSS 只读连接

Chrome 的 Apple Events 脚本运行于隔离环境，不能访问页面自身附加的 Vue 组件标识。本扩展使用官方 `chrome.scripting` 的 MAIN 环境，只在用户点击扩展并点击“连接”后读取**当前渲染组件**的有限业务字段，写入可由原生接口读取的 DOM 标记。

权限仅 `activeTab` 和 `scripting`：无永久站点权限、后台脚本、网络、Cookie、存储或发送操作。代码再次限制 `https://www.zhipin.com`；不访问全局 store、不遍历任意状态、不读取安全字段。断开会移除标记，刷新后需重新连接。仅有可核对的岗位/招聘人身份才发布标记；生产站点不暴露所需组件字段时仍无法绑定，不能视为已支持真实自动聊天。

使用 GitHub 发行附件时，先解压 `JobPilot_BOSS_Reader_0.1.2.zip`，然后在 **JobPilot 专用 Chrome** 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选中解压后包含 `manifest.json` 的 `JobPilot-BOSS-Reader` 目录。源码开发时先运行 `node scripts/build-boss-reader.mjs`，加载项目内 `.local/boss-reader`。回到已选中的 BOSS 会话，点击扩展并连接；弹窗仅显示绑定是否成功和业务字段名，不显示 ID、消息或密钥。安装与启用必须由用户明确选择，应用不会自动安装。

源码与权限均在本目录及 `packages/boss-adapter/src/page-bridge.ts`。原生发送门禁保持不变；连接不授权发送。

0.1.2 增加已有联系人的只读切换：连接后手动逐个选中过的招聘人，只有当前可见联系人组件的姓名及业务 ID 一致时才发布定位标记；虚拟列表复用或姓名变化后移除旧标记。最多在页面内存中记住 100 个曾观察过的身份，断开/刷新即清空，不写入浏览器存储。JobPilot 仍只切换应用中已导入、由用户勾选的会话，找不到时停止并提示手动打开；不会抓取隐藏联系人或滚动加载全部列表。

业务标识中的 `~` 保留原样。UID 优先作为已有会话标识；只有同一当前组件明确给出的其他业务 ID 才作为别名，不解码、不推断。姓名和公司与已有拒绝记录相同也会阻断首次联系，以免不同标识形式漏过拒绝状态。
